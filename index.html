Provably Robust Deep Classifiers

Jan 2026

This project is based on provably robust neural networks, following the work of Eric Wong and Zico Kolter in "Provable Defenses Against Adversarial Examples via the Convex Outer Adversarial Polytope" and connects to adversarial attacks from Nicholas Carlini and David Wagner.

🔎 Problem: Adversarial Attacks on Neural Networks

Modern neural networks can be fooled by adversarial examples — tiny, imperceptible perturbations to an input image that cause misclassification. Formally, an attacker solves: max‖x′−x‖∞≤ε L(fθ(x′), ytrue), meaning: stay within an ε-ball around the input, maximize the model's loss, and cause misclassification. Standard networks have no guarantees against this.

🧠 What This Project Does

Instead of just attacking networks, this project:

  • Reformulates adversarial robustness as an optimization problem
  • Applies convex relaxation to handle ReLU non-convexity
  • Uses Lagrangian duality and Fenchel conjugates
  • Derives a dual network that computes a robustness certificate
  • Enables provably robust training

This transforms robustness from "We tried attacks and they failed" into "We mathematically prove no attack within ε can fool this model".

🏗 Implementation Steps

  • Build a 3-layer ReLU neural network: Standard feedforward network (z2 = ReLU(W1x + b1), ẑ3 = W2z2 + b2) trained on MNIST. Without ReLU → linear model; With ReLU → non-convex model.
  • Formulate adversarial attack as optimization: Rewrite as minz cTẑ3 subject to ε-perturbation, network layer, and ReLU constraints. Creates a non-convex optimization problem.
  • Convex relaxation of ReLU: Compute upper and lower bounds on pre-activations, replace ReLU with convex hull relaxation. Converts feasible region into a convex polytope — the key innovation.
  • Dualize the problem: Write Lagrangian, introduce dual variables, use Fenchel conjugates, derive dual problem. By weak duality: d*(x,c) ≤ p*(x,c), so if dual value is positive, we certify robustness.
  • Interpret dual as "backward network": Dual constraints form a backward pass through the network with modified nonlinearities and ε-regularization. Defines dual network gθ(c) where robustness certificate = d*(x,c) = Jε(x,gθ(c)).
  • Robustness certificate: For every incorrect class j, if d*(x,cj) > 0 where cj = ytrue − ej, then no perturbation within ε can cause classification to class j. If true for all j ≠ true class → model is provably robust at x.
  • Robust training: Instead of minimizing L(fθ(x),y), minimize upper bound of max‖x′−x‖≤ε L(fθ(x′),y) using dual certificate L(−Jε(x,gθ(...)),y). Trains network to be robust by construction.

🧮 Mathematical Tools Used

This project combines convex optimization, Lagrangian duality, Fenchel conjugates, norm duality (ℓ∞ and ℓ1 duality), polyhedral relaxation, and robust optimization. It represents a deep intersection of machine learning, optimization theory, and functional analysis.
