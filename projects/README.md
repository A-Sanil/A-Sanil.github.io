# Project Screenshots

Place your project screenshots in this folder with the following names:

- `byow-screenshot.png` - Screenshot of your BYOW (Build Your Own World) project
- `adversarial-screenshot.png` - Screenshot of your Adversarial Probability project
- `coevolution-screenshot.png` - Screenshot of your Coevolutionary Trait Dynamics Analyzer
- `diabetes-screenshot.png` - Screenshot of your Diabetes Classifier project

## Recommended Image Specifications

- **Format**: PNG or JPG
- **Max Width**: 1200px (will be automatically resized)
- **Aspect Ratio**: Any (will maintain aspect ratio)
- **File Size**: Keep under 1MB for faster loading

The website will automatically display these images in the project sections. If an image is missing, it will be hidden gracefully without breaking the layout.
